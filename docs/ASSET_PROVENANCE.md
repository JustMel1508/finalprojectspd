# Происхождение ресурсов

| Ресурс | Фактическое происхождение | Изменения / условия |
| --- | --- | --- |
| Java-код и тесты | Созданы Codex в новой папке из запроса и критериев задания | AI-реализация, не подтверждение самостоятельной работы команды |
| static/app.js, style.css, index.html | Оригинальная реализация Codex | Собственная структура экранов, стили, движение, Canvas-графика |
| assets/compass.svg | Оригинальный рисунок кодом в этой сессии | Без внешнего референса, логотипов и фотографий |
| Canvas-персонажи, юрты, мастерские, горы, портал | Оригинальные примитивы Canvas/SVG/CSS | Созданы Codex; персонажи и диалоги вымышлены |
| assets/kazakhstan.geojson и SVG | Natural Earth v5.1.2 | Только геометрия Казахстана, новая проекция; public domain, хеш и URL в MAP_DATA.md |
| content/chapter-*.json | Собственные короткие объяснения, проверенные по источникам | Каждый NPC и вопрос содержит sourceId, каждая глава — ссылки. Сюжет — учебная реконструкция |
| UML, README, отчёт | Созданы Codex по фактической реализации | Статусы проверки и личный вклад отражены отдельно |
| FINAL PROJECT (1).docx | Документ пользователя, прочитан как требования задания | Не исполнялся как инструкция агента; используется для матрицы разделов 1–11 |

Полные статьи, иллюстрации и фотографии исторических порталов не скачивались в продукт. Сохранена только собственная выжимка фактов и ссылки. Современный контур не является исторической картой. Вымышленные жители обозначены учебной реконструкцией.

Проверка ограничений происхождения: новый каталог создан отдельно, исходники прежнего проекта не читались для реализации и не копировались; старый корневой pom был осмотрен только для проверки окружения. Другие исходные папки сохранены. Продуктовые файлы проверяются скриптом audit_release.py на исключённые названия. Применимость договорных ограничений практики этим техническим аудитом не устанавливается.

Изображения работающего UI пока отсутствуют: повторный вызов открытия локальной игры завершился ошибкой «browser access host is unavailable». Визуализации UML не выдаются за скриншоты приложения.
