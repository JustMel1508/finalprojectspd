## Состав комплекта и очистка

Сохранены исходники Java и интерфейса, тесты, десять глав, необходимые ресурсы, pom.xml, Maven Wrapper, README, отчёт и его редактируемый исходник, UML, сведения об источниках и фактическом вкладе. Личные сохранения, исходное задание и настоящая история .git не удаляются.

Удалены отдельные документы подготовки к защите `docs/defense/01-karima.md`, `02-aida.md`, `03-aisha.md`, дополнительный недельный план `docs/PLAN.md` и дублирующая текстовая выгрузка `docs/verification/git-history.txt`. Ссылки из основных документов обновлены; фактическую историю показывает `git log`, сведения о вкладе объединены в CONTRIBUTIONS.md. В окончательный архив не входят отдельные упражнения, вопросы преподавателя, временные логи, промежуточные распаковки и личные данные.

Из рабочих каталогов удалены старые логи подготовки, временные PNG проверки PDF, промежуточные распаковки, неудачные временные загрузки пакетов и два нетронутых демонстрационных снимка, созданных агентом для предпросмотра. Перед удалением снимков проверено: только demo, без попыток. Пользовательские сохранения и исходное задание не удалялись. Кеш Maven и установленные инструменты остаются в игнорируемой .tools для воспроизводимости, но не попадают в ZIP. Единственный исходник отчёта — REPORT.md, дублирующий текст из Python-рендерера удалён. Упаковщик использует явный список разрешённых папок, поэтому произвольно названный каталог пользовательских сохранений не включается случайно.

Основные исправления: согласованность JSON с контентом и событиями, строгая валидация Builder/Factory Method, повтор finish с тем же подтверждением, UUID без сокращённых форм, имя из неразрывных пробелов, feedback кнопки заданий, фокус диалогов, сохранение pending requestId между перезагрузками, защита от двойного нажатия, различимые метки карты и остановка движения при потере фокуса.

После упорядочивания папок все Java-тесты перенесены в tests/java, проверки отдельного процесса — в tests/integration, тесты интерфейсной логики — в tests/ui. Служебные скрипты находятся в scripts, PDF и REPORT.md — вместе в docs/report. Maven testSourceDirectory и все связанные пути обновлены. Повторные clean verify и проверка чисто распакованного ZIP дали те же 48/62/20 успешных проверок; 75 программных файлов совпали с проверенной копией.

## Ограничения и внешнее подтверждение

Ручное прохождение всех сцен, проверка адаптации в браузере и реальные скриншоты остаются Not run из-за недоступного browser access host. Проверки геометрии и mock DOM/Canvas не объявляются визуальным тестированием.

Код технических функций реализован; личные критерии не отмечаются выполненными без фактических подтверждений.
