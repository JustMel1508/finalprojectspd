# План реализации

Новый самостоятельный проект в history-journey. Старые исходники не используются.

1. Контент, модели, JSON-хранилище, API; один полный сценарий.
2. Шесть Java-паттернов, десять глав, Canvas-сцена, SVG-карта, два режима.
3. Проверка правил, всех глав, перезапуска и интерфейса.
4. Согласование UML, отчёта, README; воспроизводимая сборка JAR и ZIP.

План ответственности: Участник 1 — Builder/Factory Method; Участник 2 — Facade/Strategy; Участник 3 — Observer/Visitor. Имена и самостоятельный вклад пока не подтверждены. Текущая техническая реализация создаётся Codex с AI-помощью и не является доказательством самостоятельной работы студентов.

Неделя 1: сценарии, архитектура, первый уровень, демонстрация создания профиля.
Неделя 2: все главы и паттерны, демонстрация двух режимов и продолжения.
Неделя 3: тесты, исправления, UML, отчёт, сборка, репетиция защиты.
Сдача — конец учебной недели 9; защита — неделя 10. Календарные даты команда сверяет со своим расписанием.
